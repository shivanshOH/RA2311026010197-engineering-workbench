# VS Code run configuration

Open this folder in VS Code, install Microsoft's C/C++ extension (`ms-vscode.cpptools`), select **Unified Engineering Workbench (packaged)** in Run and Debug, then press F5. It starts the same root `Launch.exe` that is used by double-click launch; it does not rebuild a separate app. The extension is only needed for editor debugging and is not required by the standalone launcher.
