PowerPower boards via their own approved USB/supply inputs. Do not connect adapter VTref as a supply rail.
ConnectorJ-Link EDU Mini 9-pin 0.05-inch target connector to Nucleo CN4 6-pin 2.54 mm SWD requires a verified cable map; do not infer pin order from wire colors.
OwnershipJ-Link EDU Mini is a debug transport for a target MCU via SWD here, not a compute board; Arty FPGA uses its own USB-JTAG path.

No physical boards were connected; all adapter activity and telemetry are mock behaviour.

Safe integration sequence

Confirm exact board revisions and vendor pin tables → power each board independently → identify target reference voltage and ground → verify keyed connector map and JTAG ownership → use current-limited bench setup → enumerate only supported USB/serial interfaces → begin with read-only telemetry → add firmware or FPGA programming only after explicit target confirmation. Never hot-wire unknown headers.

One-sample handwritten backpropagation

x = 1, y = 2, h = tanh(wx+b), ŷ = vh+c, J = ½(ŷ−y)²

Forward pass
h = tanh(0.5) = 0.4621171573
ŷ = 1·h = 0.4621171573
e = ŷ − 2 = −1.5378828427
J = 0.5e² = 1.182541819
Chain rule
∂J/∂v = e h
∂J/∂c = e
∂J/∂w = e v (1−h²)x
∂J/∂b = e v (1−h²)

All initial gradients are negative, so subtracting the gradients increases parameters and raises the prediction toward y=2 for this sample.

Loss through 100 simultaneous updates

C++ implementation, learning rate 0.1; gradients at each step are computed before updating all four parameters.

Finite-difference validation

The initial analytic gradients are compared with [J(θ+ε)−J(θ−ε)]/(2ε), ε=10⁻⁶. The checked absolute tolerance is 10⁻⁵. The exact output is produced by the C++ backend at launch.
