# Data provenance

`example_ascii.stl` is a self-created one-triangle ASCII STL. Coordinates are unitless at source; the example uses a 1 by 1 right triangle in its coordinate units. The parser retains coordinates without scaling.

`synthetic_temperature.csv` is self-created, synthetic demonstration data, not an ANSYS export. Schema: node identifier; x/y/z in metres; temperature in degrees Celsius. Values are illustrative and not a solver result. Use generated FEM CSV for actual solver results.
